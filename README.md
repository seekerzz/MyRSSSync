| [Unfolded Recursive Expectation-Maximization Neural Network For Speaker Tracking](https://arxiv.org/abs/2607.26575) | 贡献点如下：<br/><br/>1. **提出了一种深度展开式RE（Recursive Exponential Mixture）网络**，用于在轻度混响环境中稳健跟踪单个移动的说话者。与经典的RE算法依赖于固定步长衰减计划不同，该网络通过将迭代过程分解为可微层来学习适应性更新策略。<br/><br/>2. **引入了步长网络（Step Size Network）**，利用FiLM（Feature-wise Linear Modulation）和PE（Position Encoding）动态调整递归权重。这些调整基于时间上下文和收敛状态进行。<br/><br/>3. **在轻度混响条件下的实验结果表明**，提出的展开式网络优于经典CREM（Compact Recursive Exponential Mixture）基线算法，后者使用空间网格搜索将估计的质心映射到物理位置。<br/><br/>4. **在单个说话者跟踪任务中**，所提出的方法的RMSE（均方根误差）比CREM基线低。这表明其在动态声学场景中有潜力提供更准确的性能。 |

| [Voice Memory for Agentic Speech Recognition](https://arxiv.org/abs/2607.26410) | ### 贡献点:<br/><br/>1. **提出Voice Memory方案**：该论文介绍了一个仅用于推理的自动语音识别(Agentic Speech Recognition)方法。此方案在流处理时，会读取一个专用于单个域的记忆.md文件，并在每次发言后决定是否基于假设采取行动或选择保持最佳候选结果而不作修改。<br/><br/>2. **异步优化机制**：在同步处理之外，通过分数门控优化器对上述记忆文件进行修订。此优化器接受仅当其修订能严格提升保留的评估分数时才被接受的编辑操作。这种方法扩展了传统的ASR-LM框架，并提出了一个"听者-思考者"架构的概念。<br/><br/>3. **耦合机制**：两个角色（听者和思考者）在记忆中相互关联，但不改变权重或学习到的技能，确保了该系统具有可审计性和通用性。<br/><br/>4. **错误修正技能的限制与提升**：研究发现，Voice Memory方案能够显著减少未受约束的生成式错误纠正(GER)中的过更正问题。例如，在金融新闻领域中，未经受限的GER可能会在高达64%的编辑中出错；相比之下，Voice Memory将这一比率降至35%。<br/><br/>5. **广泛的应用与性能提升**：跨十个HyPoradise域应用该方案时，Weighted Word Error Rate (WWR)从8.36%降低至7.52%，并且在加入三个额外的上下文示例后进一步降至7.47%。Voice Memory特别提升了包括空中交通命令和嘈杂远场语音识别（如CHiME-4）等领域的性能。<br/><br/>6. **可移植的记忆迁移**：Voice Memory方案中的记忆能够跨越不同的纠正器家族，且无需向推理路径添加任何参数就能实现这一功能。<br/><br/>7. **资源提供**：论文提供了用于未来研究的演示和示例代码。 |
